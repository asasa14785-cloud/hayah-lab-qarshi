# معمل الحياه بالقرشيه — الموقع + الباك اند + لوحة التحكم

## التشغيل محلياً (للتجربة قبل الرفع)

**الأسهل:** دبل كليك على `start-lab.bat`
- يثبت المكتبات أول مرة تلقائياً، يشغل السيرفر في نافذة مصغرة، ويفتح المتصفح على الموقع
- للإيقاف: دبل كليك على `stop-lab.bat`

**أو يدوياً:**

```bash
npm install
npm start
```

- الموقع: http://localhost:3000
- لوحة التحكم (مسار سري): http://localhost:3000/life-qarshia-9137
- كلمة السر الافتراضية: `hayat2026` — **غيرها فوراً من تبويب الإعدادات**

## هيكل المشروع

```
index.html              الواجهة (نفس تصميم code.html الأصلي)
assets/css/main.css     ستايلات الموقع المستخرجة
assets/js/tailwind-config.js  إعدادات الألوان والخط
assets/js/site-legacy.js      منطق العرض الأصلي (Fallback لو السيرفر مقفول)
assets/js/site.js             الربط بالباك اند (يجلب التحاليل/الباقات/الإرشادات/الإعدادات)
server.js               الباك اند (Express + SQLite مدمجة، بدون مكتبات خارجية)
lab.db                  قاعدة البيانات (ملف واحد — نسخه = نسخة احتياطية)
admin/index.html        لوحة التحكم (لا تعمل إلا على المسار السري + الباسورد)
code.html               نسخة أصلية احتياطية (لا تُمسح)
```

## ما تتحكم فيه اللوحة

1. **التحاليل**: إضافة/تعديل/إخفاء/تكرار/حذف + كل الحقول + **معاينة حية** كما ستظهر للزائر قبل الحفظ.
2. **الباقات والعروض**: نفس الشيء + باقة واحدة فقط "الأكثر طلباً" + **معاينة حية**.
3. **الشريط المتحرك أعلى الموقع**: إضافة/تعديل/إخفاء/حذف أي عرض + لون الشارة + الترتيب.
4. **الإرشادات**: عنوان/وصف/أيقونة/لون/رسالة واتساب.
5. **صور الموقع**: رفع اللوجو وأيقونة المتصفح وصورة المعمل والخريطة من اللوحة مباشرة (قص وضغط تلقائي).
6. **الطلبات الواردة**: تُسجل تلقائياً + رسم نشاط آخر 7 أيام في الرئيسية.
7. **الإعدادات**: رقم الهاتف **يتحدث في كل الموقع تلقائياً**، العنوان، Plus Code، المواعيد، رابط الخرائط، تغيير كلمة السر، تحميل نسخة JSON.

## مزايا إضافية

- منتقي الأيقونات والألوان في اللوحة **بالعربية مع معاينة حية** (الأيقونة بجانب اسمها، ونقطة بلون اللون).
- فورمات الموقع بقائمة منسدلة من التحاليل الحالية (تُدار من اللوحة) + **معاينة حية لرسالة الواتساب** قبل الإرسال + رسائل منسقة وتحقق من رقم الهاتف المصري.

## نسيت كلمة السر؟

شغل `reset-password.bat` واكتب كلمة جديدة (6 أحرف على الأقل)، أو: `node reset-password.js newpass123`.

## الأمان

- اللوحة على مسار سري (`ADMIN_PATH` في ملف `.env`) — غيّره لقيمة لا يتوقعها أحد قبل الرفع.
- مسارات التخمين الشائعة (`/admin` وغيرها) ترجع 404.
- الدخول بكلمة سر مشفرة (bcrypt) + جلسة JWT لمدة 12 ساعة.
- قبل الرفع: غيّر `JWT_SECRET` و`ADMIN_PASSWORD` في `.env`.
- عند الرفع على دومين حقيقي: استبدل `hayah-qarshia.com` في سطري `og:image` و`twitter:image` داخل `index.html` بالدومين الفعلي لتظهر معاينة الشعار عند مشاركة الرابط على واتساب.

## ملاحظات

- الموقع يعمل حتى لو السيرفر مقفول (يعرض آخر محتوى ثابت) — لكن التعديلات تحتاج السيرفر شغالاً.
- الصور الحالية روابط خارجية مؤقتة (`googleusercontent`) — يُنصح بحفظها محلياً في `assets/img` قبل الرفع النهائي.

## النشر على Vercel + Turso (الموقع الحي)

1. أنشئ قاعدة Turso مجانية: turso.tech ← Create database باسم hayah-lab ← انسخ URL و Token.
2. في Vercel → المشروع → Settings → Environment Variables أضف:
   TURSO_URL=libsql://....turso.io
   TURSO_TOKEN=....
   JWT_SECRET=قيمة-عشوائية-طويلة
   ADMIN_PASSWORD=hayat2026
   (واترك ADMIN_PATH الافتراضي — تغييره يتطلب تعديل vercel.json أيضاً)
3. Deploy — أول تشغيل يزرع كل البيانات والصور تلقائياً في Turso.
4. محلياً: يعمل بدون أي متغيرات (SQLite ملف lab.db).

ملاحظة: كلمة سر اللوحة تُدار من زر تغيير كلمة السر داخل اللوحة. عند نسيانها محلياً: reset-password.bat.
